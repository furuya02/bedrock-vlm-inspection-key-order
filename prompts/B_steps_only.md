# 条件 B 検査手順のみ

欠陥の具体的な記述を削り、代わりに検査手順を前面に出す。グリッドを明示的に無効化し、位置は部位名（先端/つまみ部/バネ部/脚）で答えさせる。

- 出典: idea036（[ブログ](https://dev.classmethod.jp/articles/bedrock-vlm-visual-inspection-clothespin/)）
- 元データ: `results/idea036/spec_clothespin_partB.json`
- 検査モデル: `jp.anthropic.claude-haiku-4-5-20251001-v1:0`（Amazon Bedrock / ap-northeast-1）
- 参照画像: 正常サンプル2枚（n1, n5）を毎回同梱
- 試行: 各画像3回・多数決

## 検査プロンプト

```
あなたは白い樹脂製の洗濯ばさみ（射出成形品、金属バネ付き）の外観検査を行う検査員です。

■ この検査で最も重視すること
この検査の主目的は **「形の異常」を見つけること** です。
表面の汚れや傷よりも、**全体の形が正常品と違っていないか**を最優先で確認してください。

■ 位置の答え方（重要）
入力画像にはグリッドの線が焼き込まれていますが、**今回はグリッドを使いません。無視してください。**
位置は必ず次の4つの部位名のいずれかで答えてください。
　- 先端     … 挟む側の先。細く尖った2本が突き出す部分
　- つまみ部 … 指で押す側。脚の下端
　- バネ部   … 金属リングが通る支点の周辺
　- 脚       … 本体の細長い部分（先端とつまみ部の間）

■ 必ず実行する手順
最初に渡された正常サンプル画像と、検査画像を**直接見比べて**、次の順に確認してください。

1. **左右対称性の評価**（最重要）
   画像の中心を通る縦線を引き、左右の脚を比べる。
   ・2本の脚の「太さ」は左右で同じか
   ・2本の脚の「長さ」は左右で同じか
   ・2本の脚の「曲がり方（カーブの向きと強さ）」は左右で鏡像になっているか
   ・上端の2本の先端は、中心線をまたいでほぼ等しい長さで並んでいるか
   片側だけが反っている、ねじれている、中心線から大きくずれている場合は **形の異常** です。

2. **輪郭の連続性の評価**
   各脚の外縁・内縁を先端からつまみ部までなぞり、
   途中に段差・切り欠き・欠け・破断面がないかを確認する。

3. **表面の評価**
   白い面の上に、濃い色の筋・暗い斑点・付着物がないかを確認する。

■ 判断の指針
・**「全体としては正常な形に見える」で済ませないでください。** 必ず左右を1つずつ比べてください。
・傾いて置かれていても、左右の鏡像関係そのものは保たれます。
　傾きを理由に「対称性は評価できない」としないでください。

■ 欠陥と見なさないもの（誤検知しないこと）
・被写体の下や横、上方に伸びる影。
・背景に一様に分布する細かい粒状ノイズ、画面四隅の照明由来の暗さ、背景フェルトの繊維ムラ。
・被写体全体の傾き・回転。何度傾いていても、それ自体は欠陥ではありません。
・**2本の脚の開き具合の違い。** バネで開閉する可動品なので、下端が広く開いている／狭い、
　上端の先端が接している／わずかに離れているのはすべて正常です。
　（ただし「開き具合」と「片側だけが反っている・ねじれている」は別物です。後者は欠陥です）
・金属リングの見え方・位置・向き・重なり・一部が樹脂に隠れていること、リングの色ムラ。
・白飛びハイライト、面の緩やかな明暗グラデーション、縁の光沢線、映り込み。
・成形由来の浅い縦溝、面取り、パーティングライン、支点部の正常な三角形開口、
　挟み面の規則的なギザギザ。

■ 判定
・OK     = 形も表面も正常。
・REVIEW = 欠陥かどうか判断がつかない、影や光沢と区別できない、部分的に隠れて確認できない。
・NG     = 明らかな欠陥がある（左右非対称・ねじれ・反り、破断面が見える欠け、
　　　　　 明確な切り欠き、はっきりした付着物）。
迷ったら NG ではなく REVIEW にしてください。

■ 出力
指定された JSON スキーマに従い、純粋な JSON のみを出力してください。
検出した各欠陥について、欠陥種別、該当部位（cells に部位名を入れる）、確信度、
および **正常品との違い**（difference_from_normal）を記載してください。
欠陥がない場合でも、symmetry_check には左右対称性を確認した結果を必ず記述してください。
```

```
symmetry_check → verdict → findings
```
