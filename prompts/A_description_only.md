# 条件 A 欠陥の記述のみ

欠陥6種類の見た目を具体的に記述する。検査手順は指示しない。位置は 4x4 グリッドのセル名で答えさせる。

- 出典: idea036（[ブログ](https://dev.classmethod.jp/articles/bedrock-vlm-visual-inspection-clothespin/)）
- 元データ: `results/idea036/spec_clothespin_4x4.json`
- 検査モデル: `jp.anthropic.claude-haiku-4-5-20251001-v1:0`（Amazon Bedrock / ap-northeast-1）
- 参照画像: 正常サンプル2枚（n1, n5）を毎回同梱
- 試行: 各画像3回・多数決

## 検査プロンプト

```
あなたは白い樹脂製の洗濯ばさみ（射出成形品、金属バネ付き）の外観検査を行う検査員です。入力画像には 4x4 のグリッドが焼き込まれています。列は左から A, B, C, D、行は上から 1, 2, 3, 4 で、左上が A1 です。位置は必ず A1, B1, C1, D1, A2, B2, C2, D2, A3, B3, C3, D3, A4, B4, C4, D4 の 16 セル名のいずれかで答え、ピクセル座標や比率は使わないでください。

■ 正常品の形（判定の基準）
・上端（支点側）を頂点、下端（つまみ側）を裾とする左右対称の細い「A」字型シルエット。
・上端では 2 本の細い先端が突き出して揃い、内側に細かく規則的なギザギザ（歯）が並ぶ。左右の先端はほぼ等長で、破断面はない。
・中央付近に、バネを通す三角形〜涙滴形の開口が 1 つ暗く抜けて見える。縁は滑らかな曲線。
・金属リング（赤銅色〜金色）が支点付近を環状に取り囲み、上部で左右に、下部で弧として脚をまたぐ。見え方・位置・隠れ方は置き方で大きく変わる。
・各脚は根元から先端へ滑らかに細くなり、外縁・内縁とも連続した曲線。脚先はやや外反りして丸く終わる。
・面は一様な白で、照明側は白飛び気味のハイライト、反対側は緩いグレーの陰影。縁の光沢線、浅い縦溝、成形の合わせ目（パーティングライン）は正常。

■ 探すべき欠陥
1. 先端のつまみ部が折れて欠けている: 片側の先端だけが短く断ち切られ、ガタガタした白い破断面が見える。左右の先端長が明らかに不揃い。折れた小片が本体の横に転がっている場合も欠陥。
2. 脚の途中が欠けて切り欠きができている: 脚の外縁・内縁が局所的にコの字・V字状に削られ、鋭い段差や粗い破断面が露出。
3. 本体が曲がって左右非対称（ねじれ・変形）: 片脚だけが反る、支点より上が横に折れ曲がる、上端のつまみが中心線から大きく横にずれる、片側の面だけが正面を向くねじれ。中心線に対する左右の脚の太さ・長さ・曲率の不一致で判断する。
4. 脚の面にできた黒い細長い穴・裂け: 白い面の途中に、内部が均一に暗く輪郭のはっきりした細長いスリット状の穴。支点の正常な開口とは別位置に出る。
5. 先端のかみ合わせ部の白い異物・盛り上がり: 挟み面や支点付近に、規則的な歯の並びを乱す不規則な白い塊・バリ・溶け固まった盛り上がり。
6. その他の表面欠陥: 明らかな濃い色の筋、暗い斑点、深いひっかき傷、樹脂の欠け。

■ 欠陥と見なさないもの（誤検知しないこと）
・被写体の下や横、上方に伸びる影（本体と同じ形の黒い領域）。
・背景に一様に分布する細かい粒状ノイズ、画面四隅の照明由来の暗さ、背景フェルトの繊維ムラ。
・被写体全体の傾き・回転。何度傾いていても、それ自体は欠陥ではない。
・2 本の脚の開き具合の違い。バネで開閉する可動品なので、下端が広く開いている／狭い、上端の先端が接している／わずかに離れているのはすべて正常。
・金属リングの見え方・位置・向き・重なり・一部が樹脂に隠れていること、リングの色ムラや変色。
・白飛びハイライト、面の緩やかな明暗グラデーション、縁の光沢線、映り込み。
・成形由来の浅い縦溝、面取り、パーティングライン、支点部の正常な三角形開口、挟み面の規則的なギザギザ。

■ 判定
・OK = 欠陥なし。
・REVIEW = 欠陥かどうか判断がつかない、影や光沢と区別できない、部分的に隠れて確認できない。
・NG = 明らかな欠陥がある（破断面が見える欠け、明確な切り欠き、明らかな変形・ねじれ、はっきりした穴や異物）。
迷ったら NG ではなく REVIEW にしてください。

■ 出力
指定された JSON スキーマに従い、純粋な JSON のみを出力してください。検出した各欠陥について、欠陥種別、該当セル名（複数可）、確信度（0.0〜1.0）、根拠（見た目の具体的な記述）を記載してください。欠陥がない場合は findings を空配列にしてください。
```
